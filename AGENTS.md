# my-pi

## Package management

Use `pnpm`. Wrap every dependency installation or update in Socket Firewall: `sfw pnpm install`, `sfw pnpm add <package>`, or `sfw pnpm remove <package>`.

## Agent skills

### Issue tracker

Issues live as GitHub issues in `iamivanhx/my-pi`, managed via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, used verbatim as label strings. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.

### Pinned skills

The project-selected Matt Pocock and designer skills, immutable commit pins, and pin-bump procedures live in `docs/skills/mattpocock.md` and `docs/skills/designer.md`.
